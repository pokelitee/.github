# PokéLitee

Pokémon-related apps, tools, and resources.

PokéLitee is a collection of community-focused projects built around the Pokémon universe, including game data, utilities, and companion applications.

Projects are independently developed and are not affiliated with or endorsed by Nintendo, The Pokémon Company, or Niantic.

## Projects

- [PokéDB](https://github.com/pokelitee/pokedb): generation-aware Pokémon datasets from PokéAPI.
- [Leak Duck](https://github.com/pokelitee/leak-duck): Pokémon GO data collection and a JSON API.
- [PoGo Calendar](https://github.com/pokelitee/pogo-calendar): an event calendar and companion tools using Leak Duck data.

Each repository's README links to setup and documentation. See the [shared contribution guide](https://github.com/pokelitee/.github/blob/main/CONTRIBUTING.md) to contribute.
